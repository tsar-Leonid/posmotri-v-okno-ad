# Посмотри в окно

Учебный проект Яндекс Практикума. Приложение показывает видео с видом из окна в разных городах. Можно выбрать город и время суток и найти подходящие ролики.

## Что сделано

- Свёрстан лейаут страницы на flexbox по макету.
- Стилизованы тексты, форма поиска, кастомные чекбоксы и кнопки.
- Свёрстаны состояния интерактивных элементов: `:hover`, `:active`, `:focus-visible`.
- Длинные названия и описания карточек обрезаются (`text-overflow`, `line-clamp`).
- Прелоадеры показываются поверх блока с видео и списка карточек.

## Технологии

- HTML
- CSS (Flexbox)
- JavaScript (готовая логика приложения)
